# FastAPI 项目规则

## API设计约定

### 路由结构
- 所有路由在 `api/` 目录下
- 路由文件名格式: `{resource}_router.py`
- 路由前缀使用资源名复数形式
- 使用标签进行路由分组

### 端点设计
- 使用 RESTful 设计原则
- HTTP 方法语义化使用
- 统一的响应格式
- 适当的HTTP状态码

### 请求/响应模型
- 使用 Pydantic v2 模型
- 所有模型必须有类型提示
- 添加字段描述和验证
- 使用 `from_attributes = True` 支持ORM

## 错误处理约定

### 标准错误响应
```python
{
    "detail": "错误描述",
    "error_code": "ERROR_CODE",
    "timestamp": "ISO8601时间戳"
}
```

### HTTP状态码使用
- 200: 成功
- 201: 创建成功
- 400: 请求错误
- 401: 未授权
- 403: 禁止访问
- 404: 资源不存在
- 500: 服务器错误

## 数据库约定

### 异步操作
- 所有数据库操作必须异步
- 使用 AsyncSession
- 正确的事务管理
- 连接池配置

### 查询优化
- 使用索引
- 避免N+1查询
- 使用selectinload预加载
- 分页查询

## 安全约定

### 认证授权
- 使用JWT token认证
- 基于角色的访问控制
- 敏感端点需要认证
- Token过期机制

### 输入验证
- 所有输入必须验证
- 使用Pydantic验证器
- SQL注入防护
- XSS防护

## 性能约定

### 响应时间
- API响应时间 < 200ms
- 数据库查询 < 100ms
- 使用缓存策略
- 异步处理长时间任务

### 资源管理
- 连接池配置
- 内存使用监控
- 响应压缩
- 静态资源CDN

## 文档约定

### OpenAPI文档
- 所有端点必须有文档
- 添加请求示例
- 添加响应示例
- 错误响应文档

### 代码文档
- 端点功能描述
- 参数说明
- 返回值说明
- 异常说明
