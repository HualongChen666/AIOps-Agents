# Devin IDE 项目规则目录

这个目录包含项目特定的规则和约定，用于提升Devin IDE的智能性和项目理解能力。

## 规则文件说明

### python-rules.md
Python代码规范和项目约定，包括：
- 文件结构约定
- 代码风格约定
- 导入约定
- 命名约定
- 自动化检查规则
- 智能触发规则
- 项目特定模式
- 禁止模式

### fastapi-rules.md
FastAPI开发规范和最佳实践，包括：
- API设计约定
- 路由结构
- 端点设计
- 请求/响应模型
- 错误处理约定
- 数据库约定
- 安全约定
- 性能约定
- 文档约定

### project-conventions.md
AIOps Agent项目特定约定和规范，包括：
- 项目概览和技术栈
- 目录结构约定
- 开发工作流约定
- GitLab工作流约定
- 环境配置约定
- 监控和日志约定
- 安全约定
- 性能约定
- 测试约定
- 文档约定
- 故障排除约定

## 使用方法

这些规则文件会被Devin IDE自动识别和应用，用于：
- 智能代码生成
- 自动化质量检查
- 项目特定建议
- 错误检测和修复
- 最佳实践应用

## 规则优先级

1. **安全规则** (最高优先级)
2. **项目约定** (高优先级)
3. **代码规范** (中优先级)
4. **性能优化** (低优先级)

## 自定义规则

如需添加项目特定的规则，可以在此目录创建新的规则文件，文件名格式为 `{topic}-rules.md`。
